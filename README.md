# lqhuang's Ansible Collections

Every subdir is an Ansible collection.

> [!WARN]
>
> Mainly for homelab, dev and simplified workload. Use at your own risk.

## Inspiration

- [dev-sec/ansible-collection-hardening](https://github.com/dev-sec/ansible-collection-hardening): This Ansible collection provides battle tested hardening for Linux, SSH, nginx, MySQL <http://dev-sec.io/>
- [gh:computacenter-com/ansible-best-practices](https://github.com/computacenter-com/ansible-best-practices): Documentation of Ansible Best Practices <https://computacenter-com.github.io/ansible-best-practices/>
- [gh:k4yt3x/sysctl](https://github.com/k4yt3x/sysctl): K4YT3X's Hardened & Optimized Linux Kernel Parameters <https://k4t.io/sysctl>
- [gh:k4yt3x/sshd_config](https://github.com/k4yt3x/sshd_config): K4YT3X's Hardened OpenSSH Server Configuration <https://k4t.io/sshd>
- [gh:k4yt3x/nftables](https://github.com/k4yt3x/nftables): K4YT3X's template nftables script. <https://k4t.io/nft>
- [gh:k4yt3x/ssh_config](https://github.com/k4yt3x/ssh_config): K4YT3X's Hardened OpenSSH Client Configuration <https://k4t.io/ssh>
