## Included content

Please check the included content on the [Ansible Galaxy page for this collection](https://galaxy.ansible.com/lqhuang/packages).

## Using this collection

```
    ansible-galaxy collection install lqhuang.packages
```

You can also include it in a `requirements.yml` file and install it via `ansible-galaxy collection install -r requirements.yml` using the format:

```yaml
collections:
  - name: lqhuang.packages
```

To upgrade the collection to the latest available version, run the following command:

```bash
ansible-galaxy collection install lqhuang.packages --upgrade
```

You can also install a specific version of the collection, for example, if you need to downgrade when something is broken in the latest version (please report an issue in this repository). Use the following syntax where `X.Y.Z` can be any [available version](https://galaxy.ansible.com/lqhuang/packages):

```bash
ansible-galaxy collection install lqhuang.packages:==X.Y.Z
```

See [Ansible Using Collections](https://docs.ansible.com/ansible/latest/user_guide/collections_using.html) for more details.
